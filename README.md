# 2-Factored-Authorization-Microservice-

Event-driven 2FA microservice with Axon, sagas, and email confirmation.

## What it does
- Orchestrates second-factor confirmation as a workflow, not a script.
- Uses event-driven patterns to separate commands, state changes, and notifications.
- Shows auth-domain design beyond simple CRUD.

## Stack
Java, Spring Boot, Axon Framework, JPA, email integration.

## Why it matters
This is one of the stronger repositories because it shows distributed-workflow thinking and security-domain depth.
